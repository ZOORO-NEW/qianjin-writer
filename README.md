# 前进写作引擎 · qianjin-writer

> 融合人民日报/新华社专业文笔 × 自媒体爆款基因 × 用户个人风格DNA，具备自主进化能力的智能写作技能。

## 这是什么

一个专业级中文写作AI技能包，能够：

- 📝 **写专业媒体稿件**：融合人民日报/新华社的立意高度和论证逻辑
- 🔥 **写自媒体爆款**：掌握公众号/小红书/抖音/知乎/B站的爆款结构和传播规律
- 🎯 **有个人风格去AI味**：深度学习用户"qianjin"的写作DNA——直接犀利、接地气、有温度
- 🔪 **去AI味改写引擎（v2.5）**：对已成稿做手术——"不是而是"三毒分诊（假靶子/同义替换/硬凑+NNY）→ AI味分级定遍数 → 三遍改写 → L1-L4 质检报告
- 🚫 **绕弯句式黑名单（v2.8）**：抓最隐蔽的一类 AI 味——结论后置的绕弯句式（`先说X：`/`把…这件事`/`有个问题得说清楚`/`我有个感觉`）。判定标准一句话：**结论在不在前 8 个字里**；不在就重写。含八条黑名单 + 交付前一键 grep 自查命令
- 🧊 **论述句式黑名单（v2.9）**：抓"做文章的姿态"——宣布式标签起手（`最反常识的地方在于`）、演示式断言（`你把X……，Y就……`）、抬升式收束（`真正有用的地方不是X而是Y`）、拔高定语（`一个早就该回答的问题`），以及**独立成块的金句（📌 标记 / 加粗单起一行）**。AI 味分三层：逻辑层 → 叙述层 → 论述姿态层，须三层同扫
- 🧭 **六域路由（v2.14，动笔第一件事）**：先判『什么算成功』，再谈怎么写。**营销域**（要掏钱，判据＝他能不能说出凭什么信）／**操作域**（要照着做，判据＝照做能不能出结果）／**学术域**（要被评审，判据＝方法能不能复现）／**信息域**（要准确知道，判据＝有没有歧义）／**论说域**（要认同判断，判据＝能不能复述并说出边界）／**叙事域**（要读下去，判据＝中途会不会走）。六问按序问，硬指标在前、主观在后；**域定错，承重件与验收标准全错**
- 🏗️ **专业度引擎（v2.11 / 定档 v2.12 / 分域 v2.14）**：治『很顺、很像聊天，但读完不知道说了什么』。**承重件按域换**（论说→机制／规格／边界／动作；操作→入口／参数／验收／失败处理；叙事→动机／细节／冲突／节奏；营销→痛点／证据／异议／行动；信息→主体／时间／口径／来源；学术→问题／方法／证据／局限）、**文体四档**（L1 漫谈／L2 评论／L3 教程／L4 分析，**按内容定档：要动手→L3／要判断→L4／要立场→L2／要共鸣→L1，没有账号级默认值**，且每域有允许区间）、**标题六类钩子**（学术与信息域作废）、**小标题论点化**（学术与信息域必须编号）。优先级裁决：**域 > 档 > 专业度 > 可读性 > 去 AI 味 > 文学性**
- 🧱 **体裁骨架库（v2.14 按域重构，35 类）**：营销域 8 类（产品介绍／种草笔记／短视频口播／**电商详情页／直播口播／私域转化／品牌故事／简历自荐**）、操作域 5 类（工具教程／速查清单／避坑复盘／通知公告／操作指引）、叙事域 5 类（历史故事／人物纪实／个人随笔／演讲致辞／书评影评）、论说域 8 类（观点评论／行业观察／横评选型／方法论拆解／数据分析／工作汇报／历史解读／**提案路演**）、学术域 6 类（论文／综述／开题／读书报告／应试议论文／应试记叙文）、信息域 3 类（新闻通稿／**政策解读／答复口径**）。每类给信息顺序 + 最容易写砸的样子；用户没说文体时按「交付物反查」自动匹配，并在动笔前声明判定（可撤销）
- 🏺 **叙事域四件 + 续读引擎（v2.13 / v2.14）**：承重件查**动机／细节／冲突／节奏**。新增 `domains-narrative.md`：**五个走人点**（开场三句／第一次解释／800 字没顶上／结果后散场／结尾讲道理）、**六种续读钩子**（信息差／倒计时／代价升级／反常／未完成动作／身份代入，每 600–800 字一个）、**信息差四象限**、**代价阶梯**（丢面子→丢钱→丢关系→丢身份→丢底线）、抒怀子域『被说中而非被感动』。历史故事另有硬约束：**史实四层分级**（正史／异说／考古争议／民间传说），传说可造悬念但必须当场点破，不许当论据
- 📚 **小说类转技能（v2.13）**：小说、短篇、连载、网文、剧本、同人 → 转 `qianjin-novel-writer`。分界线：读者来读故事本身＝虚构作品，转技能；故事只是文章载体（说理／带货／讲史）＝留在本技能
- 🧾 **通知词/元陈述黑名单（v2.10）**：独立成节，专抓"我要开讲了"这类元陈述（`先说X`／`必须提一句`／`划重点`／`值得注意的是`）。这类词不破坏逻辑也不显辞藻，只是把写作动作说出来
- 💰 **营销域引擎（v2.6 / 判据 v2.14）**：参考奥格威/休格曼/布莱/关健明/西奥迪尼等广告经典——写前四问 → 四步骨架（标题抓人/激发欲望/赢得信任/促下单）→ 卖点翻译到场景体验 → 滑梯效应 → Slogan 五步公式 → 影响力六原则话术 → 广告法合规终检。新增**判据层**：**信任四支柱**（可验证／具体／自曝／在场，至少立三支）＋**欲望三层**（现状痛／变化后的一天／不改变的代价）＋**商业属性必须可识别**（禁伪装成新闻、第三方测评、素人自述）
- 🧬 **能自主进化**：每次写作后自动复盘，持续优化文风和表达
- 💬 **金句宁缺毋滥**：内置8种金句生成公式供按需调用，但**不强制每篇产出，也不许单独成块**（📌 标记、加粗单起一行一律不用）。金句有价值就留在叙述流里。**"每篇必须有金句"本身就是 AI 思维**（v2.9 修正）

## 核心特色

| 特色 | 说明 |
|------|------|
| 官媒立意 | 从具体事件上升到时代命题，有思想高度 |
| 爆款结构 | 钩子开头→节奏控制→自然收尾，符合传播规律 |
| 个人语感 | 正式分析中夹杂口语化表达，犀利不废话 |
| 案例驱动 | 用真实案例说话，不用空泛理论 |
| 金句手法库 | 8 种金句公式供按需调用，不设配额、不许单独成块（v2.9） |
| 专业度分档 | 按内容定 L1～L4，四问判定、开工前声明；**同一账号里教程是 L3、随笔是 L1，没有统一默认档**（v2.12） |
| 六域路由 | 先判『什么算成功』：营销／操作／学术／信息／论说／叙事，六问命中即定；域错则承重件与验收标准全错（v2.14） |
| 体裁骨架 | 35 类体裁按 6 域分组，各有信息顺序与末位动作段（v2.14） |
| 红线按域 | 营销必标商业属性、信息域不改口径、学术不代写不编文献不造数据——三类一票否决（v2.14） |
| 自主进化 | 每次写作后自动复盘，越用越懂你 |

## 快速开始

### 在WorkBuddy中使用
直接对话："帮我写一篇关于XX的公众号文章"

### 跨平台使用
1. 打开 `prompts/system-prompt-zh.md`，复制全部内容
2. 粘贴到目标平台的System Prompt / Instructions中
3. 开始写作

详细步骤见 `PLATFORMS.md`

## 支持的内容类型

- ✅ 公众号长文（观点评论/行业分析/散文随笔）
- ✅ 小红书图文（种草推荐/观点输出/经验分享）
- ✅ 抖音短视频文案（知识科普/观点评论/故事叙事）
- ✅ 知乎回答（专业分析/经验分享）
- ✅ B站视频文案（深度分析/科普解读）
- ✅ 营销/广告文案（卖货详情页/朋友圈种草/信息流/Slogan/品牌话语/销售信）

## 写作风格示例

**开头**：
> 小区广场的防诈讲座上，王阿姨认真记着"不扫陌生码"；超市促销台前，李大爷拿着宣传单反复对比"这折扣是不是真划算"——这两年，身边的老人们变了。

**判断（留在叙述流里，不单独成块）**：
> 营销要解决的，是让人信，不只是让人买。

**结尾**：
> 真心换真心，才能跟老人们一起，把这个市场做好。

## 价值观

- 正能量：建设性批评而非破坏性否定
- 真实感：不矫揉造作，不无病呻吟
- 人民立场：为普通人发声
- 文化自信：弘扬中华优秀文化
