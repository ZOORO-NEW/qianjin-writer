# 前进写作引擎 · qianjin-writer

> 融合人民日报/新华社专业文笔 × 自媒体爆款基因 × 用户个人风格DNA，具备自主进化能力的智能写作技能。

## 这是什么

一个专业级中文写作AI技能包，能够：

- 📝 **写专业媒体稿件**：融合人民日报/新华社的立意高度和论证逻辑
- 🔥 **写自媒体爆款**：掌握公众号/小红书/抖音/知乎/B站的爆款结构和传播规律
- 🎯 **有个人风格**：深度学习用户"前进"的写作DNA——直接犀利、接地气、有温度
- 🧬 **能自主进化**：每次写作后自动复盘，持续优化文风和表达
- 💬 **金句频出**：内置8种金句生成公式，每篇文章至少2-3处可传播金句

## 核心特色

| 特色 | 说明 |
|------|------|
| 官媒立意 | 从具体事件上升到时代命题，有思想高度 |
| 爆款结构 | 钩子开头→节奏控制→金句收尾，符合传播规律 |
| 个人语感 | 正式分析中夹杂口语化表达，犀利不废话 |
| 案例驱动 | 用真实案例说话，不用空泛理论 |
| 金句引擎 | 8种金句生成公式，可截图传播的表达 |
| 自主进化 | 每次写作后自动复盘，越用越懂你 |

## 快速开始

### 在WorkBuddy中使用
直接对话："帮我写一篇关于XX的公众号文章"

### 跨平台使用
1. 打开 `prompts/system-prompt-zh.md`，复制全部内容
2. 粘贴到目标平台的System Prompt / Instructions中
3. 开始写作

详细步骤见 `PLATFORMS.md`

## 支持的内容类型

- ✅ 公众号长文（观点评论/行业分析/散文随笔）
- ✅ 小红书图文（种草推荐/观点输出/经验分享）
- ✅ 抖音短视频文案（知识科普/观点评论/故事叙事）
- ✅ 知乎回答（专业分析/经验分享）
- ✅ B站视频文案（深度分析/科普解读）

## 写作风格示例

**开头**：
> 小区广场的防诈讲座上，王阿姨认真记着"不扫陌生码"；超市促销台前，李大爷拿着宣传单反复对比"这折扣是不是真划算"——这两年，身边的老人们变了。

**金句**：
> 营销不是"怎么让人买"，是"怎么让人信"；数字化不是"工具"，是"帮着建信任的手"。

**结尾**：
> 真心换真心，才能跟老人们一起，把这个市场做好。

## 价值观

- 正能量：建设性批评而非破坏性否定
- 真实感：不矫揉造作，不无病呻吟
- 人民立场：为普通人发声
- 文化自信：弘扬中华优秀文化
