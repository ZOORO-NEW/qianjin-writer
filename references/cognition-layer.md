# 写作前思考层（人类化构思 · cognition-layer）

> 本文件解决一个根问题：**AI 味的根不在词汇，在于"没想就写、先选结构再填内容"。** 真人写东西，是被材料先触动，然后结构自己长出来的。本层教 skill 在动笔前，先完成一次"读材料 → 感情绪 → 让结构涌现"的思考过程，并具备人类的情绪理解。

---

## 0. 一条铁律

**先理解，再下笔；先有情绪，再有结构。永远不要让"结构模板"先于"对内容的感受"出现。**

人类写作者面对一个题目，脑子里发生的是：

- 读材料 → "这里有个反差，有点意思"
- 再读 → "不对，真正戳我的是那个排队还道歉的狼狈感"
- 然后才 → "那我开头不能平铺，得把那个狼狈感先甩出来"

不是"翻到结构手册第五条套上去"。是**先被戳中，结构随后自然成形**。

---

## 1. 写作前思考四步（每次写作必须先走，作为隐藏思考链）

### 第一步：沉浸读材料，找"打动点"

- 不急着定结构、不急着列提纲。
- 问自己：**这段材料最打动我的是什么？** 是一个反差？一个扎心数字？一个画面？一种憋屈？一句说不清哪不对的话？
- 找到那个"打动点"，它就是全文的锚。所有结构都围着它转，而不是围着"三段式"转。

### 第二步：给文章定一个具体的"情绪底色"

- 用**一个具体情绪词**形容这篇，不是"正能量/干货"这种废话标签。
- 候选（可叠加）：无奈、愤怒、轻快、悲凉、紧迫、得意、困惑、委屈、释然、荒诞、心疼、警惕、兴奋、怅然。
- 为什么必须具体：情绪词决定节奏、句式、乃至哪里该留白。写"悲凉"和写"愤怒"用的不是一套笔法，混用就假。

### 第三步：让结构从情绪里"长出来"（不是从菜单里"选出来"）

把"打动点 + 情绪底色"放一起，问：**这种情绪，天然适合怎么讲？**

下面是一张"情绪 → 结构涌现"的理解图谱。注意：它是**理解工具，不是模板菜单**。你要的是"因为这个情绪，所以我这样讲"的因果，不是"翻到第五条套上去"。

| 情绪底色 | 自然涌现的结构倾向 | 为什么这样长 | 允许的"不规则" |
|---|---|---|---|
| 无奈 / 憋屈 | 先顺着读者预期说，再突然反转 | 读者也以为"没事"，你一反转，憋屈感翻倍 | 可倒装：结论放开头，再回头解释"我一开始也这么想" |
| 愤怒 | 短句劈脸，不解释、不层层论证 | 愤怒不需要 structured argument，需要节奏砸下去 | 段落可极短，一句一段；可不用小标题 |
| 轻快 / 趣味 | 叙事流 + 小反转点缀 | 趣味靠"事情本身好玩"，结构要松，别捆住 | 可跳叙、可倒装、可夹闲笔 |
| 悲凉 / 悲伤 | 白描 + 留白，不喊口号 | 悲伤经不起升华，一喊就假；让读者自己沉 | 结尾可停在画面，不总结；长句慢炖 |
| 数据冲击 | 先抛一个反直觉数字勾住，再拆解 | 数字本身有钩子，但要夹在故事里，不能堆 | 数字可前置到标题/开头；分析段可密 |
| 紧迫 | 倒计时 / 具体日期开头，制造时间压迫 | 紧迫感来自"还剩几天"，不是来自喊"快" | 可全篇无小标题，靠时间线串 |
| 困惑 / 求解 | 带着问题开篇，边写边想，中途改口 | 真求解的人不是全想明白才写，是写着写着清楚 | 可保留"我一开始想错了"的弯路 |
| 得意 / 揭秘 | 先抛反常识结论，再慢慢抖料 | 揭秘的爽感在"原来如此"，要吊 | 可先给答案后给过程（倒装） |
| 心疼 / 温情 | 从一个具体的人/细节切入，不宏大 | 心疼是具体的，不是抽象的"社会现象" | 可只写一个场景，不展开论点 |

### 第四步：定一个"收尾姿势"

收尾不是"升华三件套"，是根据情绪定的：

- 无奈 / 愤怒 → 留一个口子，不补（读者自己品）
- 悲凉 / 心疼 → 一个画面收，什么都不说
- 轻快 / 得意 → 一句俏皮话收，别拔高
- 数据冲击 → 一句冷静的判断收，压住
- 紧迫 → 一个动作指引收，推动

默认**不升华**（除非年终复盘这类硬需要）。

## 2. 灵活性的授权书（写进肌肉记忆）

真人写作没有"固定版式"。skill 被明确授权，以下"不规则"不仅允许，而且是去除 AI 味的利器：

- **倒装句**：结论可以放开头，过程往后放。尤其适合"揭秘 / 得意 / 反常识"。
- **正叙叙事**：也可以老老实实从头讲，尤其适合"趣味 / 轻快 / 温情"。两种都行，看内容。
- **中途改口**：可以写"等等，我得纠正自己一下"，保留思考的弯路。真人会这样，AI 不会，所以这很真。
- **段落长短不一**：情绪激烈处一句一段；平静处可长段慢炖。
- **不强制小标题**：不是每篇都要小标题。叙事流、随笔、短评可以完全没有小标题。
- **句式杂揉**：叙述里夹一句独白、夹一个问句、夹一段白描，都是真人的笔法。
- **留白**：该停的地方停住，不把话说满。满，是 AI 的恶习。

**铁律**：所有这些灵活，都必须"因为内容需要"才用，不是为灵活而灵活。判断标准就一句：**这样写，是不是比规规矩矩写，更贴这个情绪、更像真人在讲这件事？**

## 3. 思考链自检（动笔前必须能答出）

写之前，自己问三句，答不出就别动笔：

1. **我被材料里的哪个点打动了？**（答不出 = 还没读进去，先去读）
2. **用一个具体情绪词，这篇是_____？**（答"正能量/干货" = 不合格，重想）
3. **我的结构是因为这个情绪才这样，还是因为"该用三段式"？**（答后者 = 退回，先想情绪）

## 4. 与结构引擎（viral-structures.md）的关系

- viral-structures 的"八种结构 + 反套路约束"是**下限护栏**（别掉进 AI 味的坑）。
- 本层是**上限来源**（让结构从内容情绪里长出来）。
- 二者顺序：先走本层想清楚情绪与涌现方向 → 再借 viral-structures 的护栏避免翻车 → 最后成稿。
- 本层优先级高于 viral-structures 的"轮换 / 结构清单"：如果情绪明显指向某种讲法，就顺着情绪，不必为了轮换而轮换。护栏只在"翻车风险"时介入。

## 5. 情绪理解的边界（合规护栏）

情绪化不等于失控。以下情况即便"情绪上头"也要刹车：

- 涉及国家主权 / 领土 / 领导人 / 民族宗教：一律以新华社 / 人民日报官方表述为准，情绪不能为违规让路。
- 悲伤 / 愤怒可被表达，但不得煽动用对立、不得人身攻击、不得未经证实的指控（参 SKILL.md 第八章）。
- "心疼 / 温情"类内容，避免消费苦难、避免摆拍式煽情；具体、克制、留尊重。
