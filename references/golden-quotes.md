## 三、金句生成公式

### 公式1：否定+肯定（最常用）

```
X不是A，是B。
```

**示例**：
- "营销不是怎么让人买，是怎么让人信。"
- "数字化不是工具，是帮着建信任的手。"
- "私域不是卖货场，是关系沉淀池。"

**生成要点**：A是大众常识，B是更深层的本质。反差越大，金句越有力。

### 公式2：赢了X，丢了Y

```
赢了X（表面利益），丢了Y（核心价值）。
```

**示例**：
- "赢了7万的官司，丢了用户的人心。"
- "赢了流量，输了口碑。"
- "赢了短期销量，丢了品牌信任。"

**生成要点**：X和Y形成价值对比，Y比X更重要。

### 公式3：不是A，也不是B，是C

```
不是A，也不是B，而是C（本质揭示）。
```

**示例**：
- "老人们不是难伺候，也不是不想花钱，是怕被忽悠。"
- "问题不在产品，不在渠道，而在信任。"

**生成要点**：先排除两个常见归因，再给出真正的本质。

### 公式4：A是B的C

```
A是B的C（隐喻关系）。
```

**示例**：
- "互联网是情绪的发泄地。"
- "私域是关系沉淀池。"
- "数据是信任的货币。"

**生成要点**：用日常事物隐喻抽象概念，降低理解门槛。

### 公式5：排比递进

```
不是为了A，是为了B；不是为了C，是为了D；不是为了E，是为了F。
```

**示例**：
- "用直播不是为了卖货，是为了让人看见你的实在；建数据库不是为了精准推销，是为了知道人家需要啥；加微信不是为了发广告，是为了多帮人家点忙。"

**生成要点**：三组对比，形成节奏感，最后一组升华到价值观。

### 公式6：当A变成B，C就会D

```
当A（现状）变成B（理想状态），C（结果）就会D（自然发生）。
```

**示例**：
- "当企业与用户从'买卖关系'变成'共生关系'，增长便会水到渠成。"
- "当信任建立起来，交易只是顺带的事。"

**生成要点**：描绘一个转变过程，结果自然引出。

### 公式7：越是A，越要B

```
越是A（困难/趋势），越要B（正确的做法）。
```

**示例**：
- "越是信息透明，越要真心待人。"
- "越是竞争激烈，越要回归本质。"

**生成要点**：A是当前挑战，B是正确应对。

### 公式8：A的人不是B，是C

```
A的人（群体）不是B（误解），是C（真相）。
```

**示例**：
- "老人们不是难伺候，是怕被忽悠。"
- "取消购物车的人不是不买东西，是更知道要什么。"

**生成要点**：打破对某群体的刻板印象。

## 四、金句使用位置指南

### 4.1 文章开头（定调金句）

**作用**：一开篇就给全文定调，让读者知道这篇文章有"料"。

**适合类型**：否定+肯定型、赢了X丢了Y型

**示例**：
> "赢了7万的官司，丢了用户的人心。" ——开篇直接抛出这个判断，读者会想知道为什么。

### 4.2 段落结尾（小结金句）

**作用**：每个大段落结束时，用一句话总结，强化记忆。

**适合类型**：A是B的C型、越是A越要B型

**示例**：
> 段落分析完盒马的供应链问题后："会员体系的朝令夕改，本质上是对用户价值承诺的失信。"

### 4.3 文章结尾（升华金句）

**作用**：全文最核心的传播点，读者看完后记住的最后一句话。

**适合类型**：排比递进型、当A变成B型

**示例**：
> "营销不是'怎么让人买'，是'怎么让人信'；数字化不是'工具'，是'帮着建信任的手'。真心换真心，才能把市场做好。"

## 五、金句自检标准

一个好金句必须满足以下标准：

| 标准 | 说明 | 自检方法 |
|------|------|----------|
| **可独立传播** | 脱离上下文也能成立 | 截图发给朋友，不看全文能理解吗？ |
| **有信息量** | 不是正确的废话 | 删掉它，文章是否少了什么？ |
| **有反差感** | 打破预期或常识 | A→B的反差够不够大？ |
| **有节奏感** | 读起来顺口，有韵律 | 大声读一遍，是否拗口？ |
| **不矫情** | 自然流露，不刻意 | 是否像"硬憋出来"的？ |
