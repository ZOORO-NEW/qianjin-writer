# 文学质感增强 · literary-craft

> 本文件从中文名著名家中提炼**可迁移到自媒体写作**的修辞手法，作为 qianjin-writer 的「润色层」与「金句层」增强。  
> **使用纪律（务必遵守）**：
>
> 1. 这些技法只用于句子质感与金句打磨，**不碰爆款结构层**（钩子、分段、完读率逻辑由 viral-structures.md 负责）。
> 2. 一篇公号长文里，文学技法**最多用 1-2 处**点睛。多了就是文艺腔，完读率会崩。
> 3. 名著名句为记忆引用，大意为准；标注「仿写」的段落是风格示范，非原作者原句，禁止当成名言引用。
> 4. 目标：让读者觉得「这句写得好、像真人」，而不是「这人在掉书袋」。

## 一、钱钟书 · 反差比喻与学术讽喻

### 技法 1.1 喻体陌生化（俗物反比）

**原则**：喻体选读者熟悉、但没人拿来比喻的俗物，制造「对，但没人这么说过」的顿悟。严禁用「灯塔 / 基石 / 航船 / 引擎」这类被用烂的宏大意象。

**原著名句（围城）**：婚姻像一座围城，城外的人想进去，城里的人想出来。

**自媒体改写示范**（写 AI 课）：

> 市面上的 AI 课，名字都叫「增长」「破局」「认知升级」，听着像成功学。其实它干的事，跟小区门口理发店办卡没两样：先让你觉得不弄就落后了，再告诉你卡能分期。

### 技法 1.2 学术腔讽喻小事

**原则**：用一本正经的论文体去描述一件荒唐小事，反差本身就是幽默。适合拆穿伪概念、伪干货。

**原著名句（围城·大意）**：一个人的缺点正像猴子的尾巴，猴子蹲在地上时看不见，等它爬上树，就把后部供给大众瞻仰。

**自媒体改写示范**（写「底层逻辑」体）：

> 经我观察，标题带「底层逻辑」四个字的文章，九成没有逻辑，剩下一成的逻辑是「你该买课了」。这门学问的底层逻辑，就是没有底层。

## 二、汪曾祺 · 白描与闲笔

### 技法 2.1 白描删修饰

**原则**：删掉所有程度副词（很 / 非常 / 十分 / 极其）和抽象形容词，用具体名词 + 动词堆叠画面。信息密度来自名词，不来自形容词。

**原著名句（大意）**：到了一个地方，吃一碗热面，加一个煎蛋，坐下来看一会儿街上的人。

**自媒体改写示范**（写工具实测）：

> 我用了三天，每天开八个文档，导出十二张图，错了四回。第四回才把格式调对。  
> （远强于「我深度体验了非常强大的功能，感受十分震撼」）

### 技法 2.2 闲笔造生活气

**原则**：在说理中间插一句「无关」的感官细节，读者会觉得你是个真人，不是生成器。

**自媒体改写示范**（写写作卡壳）：

> 改到第三稿，窗外楼下在炒辣椒，呛得我打了个喷嚏。就这一下，我突然知道开头该怎么写了。

## 三、鲁迅 · 平静叙述与寸铁

### 技法 3.1 平静说残酷

**原则**：越残酷的事，语气越平。不用感叹号，不用「令人发指」，平铺直叙反而压人。

**原著名句**：我家后院有两棵树，一棵是枣树，另一棵也是枣树。

**自媒体改写示范（仿写，非原句）**（写被割韭菜）：

> 他买了第七个 AI 课。钱包空了。他说这次真的学会了。

### 技法 3.2 寸铁杀人

**原则**：一句话戳破一个流行伪装，不展开、不论证，留白让观众自己品。

**自媒体改写示范**（写「免费」）：

> 免费的尽头，是你要花更多钱才能回到免费之前的状态。

## 四、张爱玲 · 感官物象与苍凉比喻

### 技法 4.1 把情绪译成物象

**原则**：把抽象情绪翻译成颜色 / 质地 / 气味 / 温度的具体物。读者「感到」，而非「被告知」。

**原著名句**：生命是一袭华美的袍，爬满了蚤子。

**自媒体改写示范**（写焦虑）：

> 那段时间我打开电脑就嗓子发干，像刚跑完步。屏幕白得刺眼，光标一闪一闪，像在笑我。

### 技法 4.2 华丽写荒凉

**原则**：用华丽词写荒凉事，反差出宿命感。适合收尾点睛，不宜多。

**自媒体改写示范（仿写）**（写免费陷阱）：

> 免费的馅饼端上桌时，盘子底下压着账单。你吃得很香，吃完才发现，连盘子都是租的。

## 五、老舍 · 口语节奏与俗白比喻

### 技法 5.1 口语短句

**原则**：用北京口语的短句和语气词（呢 / 吧 / 嘛），像人说话，不像机器播报。

**原著名句（大意）**：事儿不大，可架不住天天有。天天有，就成了大事。

**自媒体改写示范**（写工具提效）：

> 这功能吧，单看没啥。可它天天替你省那五分钟，一个月下来，够你多看两部电影了。

### 技法 5.2 俗白比喻

**原则**：比喻用老百姓过日子的事物，不用宏大意象。

**自媒体改写示范**（写卡顿）：

> 老款电脑跑新软件，跟六十岁大爷学滑板似的，摔是迟早的事。

## 六、落地检查（写完用这条过一遍）

- [ ] 全文文学技法 ≤ 2 处，且都在「点睛位」（开头钩子 / 金句 / 结尾）
- [ ] 没有「灯塔 / 基石 / 航船 / 在这个XX的时代」这类被用烂的宏大意象
- [ ] 没有无病呻吟的景物描写（风轻轻吹过、岁月静好）
- [ ] 每个比喻的喻体是具体的、俗的、读者一眼能脑补的
- [ ] 读 aloud 一遍，不像「语文课文」、像「一个懂行的人在跟你聊」
