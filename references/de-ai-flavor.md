# 去 AI 味改写引擎 · de-ai-flavor

> v2.5 新增。与 `anti-patterns.md`（认识坏样长什么样）互补：本引擎是**对已成稿 / 初稿做手术的流程**——三毒分诊 → AI 味分级 → 三遍改写 → 收敛终止 → L1-L4 质检报告。
> 适用触发：用户说"这稿子 AI 味太重""帮我改得像人写的""润色去味""我说话怎么越来越像 AI"。
>
> **两条手术铁律**：
> 1. **改最少，效果最大**——能改一个词，不改一句；能删一句，不重写一段；没问题的句子尽量保留。
> 2. **保留创作意图**——只改"怎么说"，不改"说什么"。观点、案例、走向一律不动，不新增原文没有的内容。

---

## 一、先懂病根（为什么 AI 味读着累）

- **文字恐怖谷**：句句通顺、辞藻华丽、语法完美，但没有活人情绪与温度——看着像人，细看全是塑料花。
- **力竭机制**：AI 是概率模型，永远选"最安全、最平均"的词。读者大脑的预测次次被命中，自动进入节能模式跳过——于是"读着累、读完什么都没留下"。**去 AI 味的本质 = 给文字重新制造"意料之外"。**
- **语料污染循环**：AI 吃人写的稿 → 人读多了 AI 腔开始模仿 → AI 再吃这些被腌过的稿，味儿越来越重。去 AI 味不只是在改文案，是在抵抗语感被侵蚀。

---

## 二、"不是A而是B" 三毒分诊（最高优先级专项）

> 这是 AI 最标志性的毒句式。**毒不在句式本身，在用法。** 每处先判定属于哪一毒，再动手，不许一律照删（金句库的"对仗型 A 不是 B 是 C"是真金句，删错可惜）。

### 毒 1：假靶子（虚空打靶）
AI 先立一个**根本没人会做**的判断当靶子，否定它，再抛自己观点，显得深刻严谨。
- 例："AI 改变的不是工具，而是生产关系。"——谁说过 AI 改变的是工具？
- 判定：前半句否定的观点不存在 → **直接删前半句，只留 B**。

### 毒 2：同义替换（A = B）
A、B 是同一件事，只是前半句换了个更虚浮的说法，硬凑转折。
- 例："她不是在演风，而是在演一种失控感。"——风就是失控感。
- 判定：A、B 同一件事两种说法 → **合并成一句，删掉"不是而是"脚手架**。

### 毒 3：无关硬凑（含 NNY 变体）
在不需要转折的地方强行"不是而是"；NNY 变体 = "不是 X。不是 Y。只是 Z。"，先否定两项再抛观点，刻意制造悬念但内容平淡。
- 判定：删掉"不是而是"后句子意思毫无损失 → **直接删**。

### 好用法对照（别误杀）
- ✅ 好："我爱上的不是你的容貌，而是你的灵魂。"——真有人会做"爱容貌"这个判断，且容貌 ≠ 灵魂。
- ❌ 毒："不是在演风，而是在演失控感。"——没人这么判断，且两者同义。

### 通用修法
直接说 B；或改递进 **"不仅是 A 更是 B"**——递进比否一肯一自然得多，且不制造假靶子。

## 三、AI 味分级（决定手术强度）

| 指标 | 轻度 | 中度 | 重度 |
|---|---|---|---|
| 破绽词密度（/千字，见第六节清单） | ≤5 | 6-15 | >15 |
| 连续排比段数 | ≤2 | 3-4 | ≥5 |
| 心理词占比（感到/觉得/明白/意识到） | ≤10% | 10-25% | >25% |
| 平均段落句数 | ≤3 | 3-5 | >5 |

**取最高档**。无重度、且中度 ≥ 3 项 → 按中度处理。
- 轻度 → 只过 Pass 1　- 中度 → Pass 1 + 2　- 重度 → 完整三遍 + 重点段落整段重写

---

## 四、三遍改写流程

**Pass 1 · 去泛化**：破绽词 → 具体动作 / 细节（清单见第六节）；"他很紧张" → "他的手在抖"（展示，不告知）；连续排比打断（保留 1-2 个最强的）；对话标签用动作 / 上下文替代；标点修复。

**Pass 2 · 去书面化**："不是而是"逐处过三毒分诊再修；连接词精简（此外 / 然而 / 因此 → 删或换隐性连接，全文 ≤2）；修饰词清扫（一次只留一个形容词）；系动词恢复（"作为 / 充当 / 拥有" → "是 / 有 / 在"）；伪精确数字去假严谨；莫名其妙的比喻拆掉（喻体与本体无逻辑关联 → 白描或直接删）；被动语态找出执行者放句首。

**Pass 3 · 回自然感**：节奏打碎（长短句交错，一句话自成一段制造重点，每篇 ≤2 次防滥用）；对话去腔调（口语词、承认不足）；**结尾去升华**（用动作 / 场景 / 一个未答的问题收尾，不用总结感慨——见 viral-structures 升华反射）；补具体感官细节；允许跑题、题外话、半成型想法；在情绪高点用极短句独立成段（句式断裂）。

**收敛终止（Phase 4）**：同一段连续两轮无新改动 → 停止该段；全文上限 3 轮；第 3 轮仍有 ≥10 处 → 标注 **[需复核]**，交给用户定夺，不硬改。

## 五、L1-L4 质检金字塔

> 借鉴测试金字塔：从基础规则到主观判断，层层递进。任何一层不过就返工，不许跳过。

- **L1 硬性规则（自动扫描，零例外）**：①破绽词 ②三毒句式 ③高频堆叠副词（极其 / 猛地 / 死死 / 狠狠 / 稳稳 / 仿佛 / 瞬间 / 紧接着——一段内重复即标）④禁用标点（冒号：破折号—— 双引号""）⑤结构套话（"让我们来看看""在当今…的时代""先说答案""掰开了揉碎了"）⑥空泛工具名。**六项零命中**才过。
- **L2 风格一致（模式匹配）**：开头是否从具体当下事件切入、第一句让人想读第二句？有无长短句交替与短句断裂？有无口语化 + 故意打破 + 至少一处自嘲？标点禁令二次确认？L2 开头 / 标点必须过，其余 ≥3/4。
- **L3 内容质量（深度审查）**：每个核心观点有具体人 / 场景 / 细节 / 数据支撑？知识是"聊着聊着顺手掏出"而非"下面我来科普"？讲立场时有无对对方立场的理解承认？多产品对比是否逐一展示而非一次性罗列？L3 前两项必须过。
- **L4 活人感终审（最终人格层）**：以读者视角通读——**这是一个真人在认真跟我聊，还是 AI 在输出信息？**温度感（体感记忆 vs 知识描述）/ 独特性（只有这个作者会写的角度）/ 姿态（"有见识的普通人在认真聊"，非导师教学生）/ 心流（无注意力断点）。任一"AI 味重"即返工。

## 六、破绽快速检查清单（交付前逐项过）

- "不是 A 而是 B" 三毒（假靶子 / 同义替换 / 硬凑 + NNY"不是 X 不是 Y 只是 Z"）？
- 高频堆叠副词一段内重复？
- **伪精确数字**（"一步跨 50cm，这次跨了 49cm"这类假装严谨）？删或正常化
- **科普起手式**："先说答案""掰开了揉碎了""拆解""你品一下"？删，直接进内容
- **自问自答老师腔**："这叫什么？这叫 XX。""说明什么？"？删，直接陈述
- **三字鉴定词**："声音很平""氛围感强"这类鉴定词？换成具体描写
- **元评论**："本文接下来将…"？删
- **模糊归因 / AI 幻觉**："行业专家认为""某大学实验显示""NASA 科学家算了一笔账"？核实，查无实据就删（交叉 3.3 七问第 ① 条，一票否决）
- 空泛工具名（"某个 AI 工具 / 某模型"）？换成具体名称（交叉第三节记忆点）
- 连接词（此外 / 然而 / 因此）超过 2 处？删
- 被动语态？执行者放句首
- 教科书开头（"在当今…的时代"）？换具体事件切入
- 连续句子长度相同？打断一个
- 情感告知（"他很紧张"）？改动作
- 破折号 / 冒号 / 双引号？替换（此处及 Pass 阶段针对的是一般自媒体文体；通稿、公文等按对应文体规范执行）

## 八、与其它 references 的分工

- **anti-patterns.md** = 坏样词典（文学腔 / 排比 / 伪金句 / 假升华 / 成语 / 套话前缀 / 感叹号），本文不重复展开，扫到直接照它的正确示范修。
- **cognition-layer.md** = 写作前的情绪 → 结构涌现（防 AI 味的根子在上游：先被打动再动笔）。
- **viral-structures.md** = 结构层反套路（七宗罪 / Unexpected Beat / 结构指纹），本文 Pass 3 的"结尾去升华"照它执行。
- **literary-craft.md** = 文学质感的"加点"，本文只做"去味"的"减点"，一篇里加点 ≤2 处。
