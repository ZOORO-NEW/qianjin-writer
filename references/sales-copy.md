# 营销文案 / 广告文案引擎（sales-copy）

> 一句话心法：**文案不是炫技，是攻心；广告的唯一目的是销售。**
> 卖货文案只有四步：**抓眼球 → 激欲望 → 建信任 → 促下单**（好奇-欲望-相信-行动）。
>
> 方法论出处（全部可查原书）：奥格威《一个广告人的自白》《奥格威谈广告》· 约瑟夫·休格曼《文案训练手册》· 罗伯特·布莱《文案创作完全手册》· 关健明《爆款文案》· 西奥迪尼《影响力》· 特劳特《定位》· 华杉华楠《超级符号就是超级创意》· 乔治·路易斯《蔚蓝诡计》。本引擎是把这些书里可执行的部分压缩成工序，不是书单复述。

---

## 1. 写前四问（商业思考层，先于任何文字）

写文案前先答四个问题，答不出就去找，找不来就问用户，不许硬写：

| # | 问题 | 答不出怎么办 |
|---|------|-------------|
| Q1 | **卖什么**：产品/服务核心是什么？一句话说清 | 说不清=定位模糊，先让用户讲产品时最得意的那一点 |
| Q2 | **卖给谁**：哪类人？此刻在什么场景、正烦什么 | 不要人口学画像（25-35岁女性），要"周一早高峰挤地铁刷手机的上班族" |
| Q3 | **要 TA 做什么**：下单/领券/加购/关注/到店/转发？ | 一篇文案只允许一个行动目标，贪多必散 |
| Q4 | **凭什么信**：证据链（参数/认证/销量/背书/试用）够吗 | 不够先去要；**证据不许编**（红线，同七问第 1 条） |

**定位自检（特劳特）**：先写一句话差异化——"在____（哪类人）心里，我们是____（品类）里____（第一/唯一/最懂…）的那个"。写不出差异化，就是还没找对卖点，先回去找，别急着遣词造句。反例：人人都能说的"高品质/好服务/值得信赖"不是定位，是废话。

## 2. 卖点翻译机（特征 → 利益 → 体验）

参数没人买账，**利益才动人，体验最勾人**。同一样东西，三个说法三个转化率：

```
物理特征（说明书语言）  →  用户利益（理性的"有什么用"）  →  生活场景体验（感性的"那一刻"）
"304不锈钢，保温12小时" →  "一整天都能喝到热水"          →  "冬天开会两小时回来，拧开杯盖还是烫嘴的"
```

- **场景法（休格曼）**：不要描述产品，描述拥有产品后的一个瞬间。"客户买的不是朝南的窗户，是下午两点不用开灯的那个下午。"
- **概念销售（休格曼公理 9）**：推销概念，不推销产品。卖的不是钻头，是墙上的洞；卖的不是恒温器，是"家里温度你说了算"。
- **情感卖、理性解释（休格曼）**：情绪负责让 TA 说"我想要"，道理负责给 TA 一个"凭什么买"的交代。两个都要，缺一个就只感动了自己。
- **具体 > 抽象**：能写"第 3 天见效"不写"见效快"；能写"一杯水可感知的精准（100克）"不写"极致精准"（小米体重秤案例）。
- **反例自查**：通篇只剩形容词（超好用/高品质/匠心/极致）→ 全部换回名词+动词+可验证细节。

## 3. 销售型文案四步骨架（关健明《爆款文案》18 法精华）

任何卖货内容（详情页/推文/朋友圈/信息流）都能用这四步检查自己的转化缺口在哪。**少一步，读者就在那一步流失。**

### 第 1 步 · 标题抓人眼球（5 种句式，选一种，别混搭）

| 句式 | 原理 | 示例 |
|------|------|------|
| ① 新闻社论 | 广告没人看，新闻有人看——穿上记者马甲 | "丹麦生蚝泛滥没人吃？中国吃货坐不住了" |
| ② 好友对话 | 推销被拒，闲聊被听 | "嘿，你是不是也受够了一到冬天手脚冰凉" |
| ③ 实用锦囊 | 给出苦恼+破解方法，引发收藏欲 | "秃头救星：3 招让发际线回来" |
| ④ 惊喜优惠 | 亮点+具体低价+限时限量 | "原价 399 的保温杯，今天 99，仅限 500 个" |
| ⑤ 意外故事 | 坏开局→反转→信赖（差开局让读者产生优越感"他都能行我更行"） | "被裁员的第 30 天，我靠一个杯子月入过万" |

标题法则补充（布莱 4U）：好标题尽量同时踩 Urgent 紧迫 / Unique 独特 / Ultra-specific 具体 / Useful 有用。4 个踩不齐，优先保"具体"和"有用"。

### 第 2 步 · 激发购买欲望（6 种技法，一次用 2-3 种即可）

- **感官占领**：写听/看/闻/尝/触，让读者隔着屏幕"过一遍"。"一口咬下去咔嚓一声，香到骨子里"（写零食）；写护肤品就写质地推开的感觉，不写"质地清爽"。
- **恐惧诉求**：展示痛苦场景+不解决的后果（"冬天喝到凉透的热水，胃里像揣着一块冰"）。慎用，别渲染过头，恐吓式文案伤品牌。
- **认知对比**：先指竞品的短板（或常见方案的麻烦），再亮自己的长板。对比要客观有据。
- **使用场景**：把产品埋进多个真实生活瞬间——通勤路上/加班深夜/追剧时/见客户前。
- **从众心理**：展示销量/用户量/好评数（必须有真实数据支撑）。
- **理想自我**：让 TA 看到用了之后"更好的自己"（更自律/更体面/更被爱），比卖功能更贵。（关健明称之为正当消费的钩子之一）

### 第 3 步 · 赢得读者信任（3 种技法，至少用 2 种）

- **权威转嫁**：奖项/认证/专家推荐/大客户名单/权威媒体背书，要具体可查（"XX 认证"必须真有这个认证）。
- **事实证明**：列数据、讲实验/演示、**链接熟悉事物**把陌生数字翻译成体感（"100 克，喝杯水都能感知的精准"）。
- **化解顾虑**：主动替读者问出"售后怎么办/会不会交智商税/物流多久"，再给方案（"30 天无理由退，运费我们出"）。把反对问题在文案里提前答完（休格曼公理 13：预测并回答读者的问题）。

### 第 4 步 · 引导马上下单（4 种技法，选 1-2 个收尾）

- **价格锚点**：先给一个贵的参照（原价/竞品价/线下价），再亮出本价，落差即划算感。
- **算账**：把总价摊到每天/每次，变成"零钱级"决策（"一天不到一块钱"）。
- **正当消费**：给购买一个体面理由——健康、上进、孝心、送礼、犒劳自己。人愿意为"理由"付钱，不愿为"欲望"承认付钱。
- **限时限量**：营造真实稀缺（限量款/活动截止）。**必须是真稀缺**，虚假倒计时是虚假宣传（红线）。

> CTA 铁律：行动指令要具体、无脑、一步到位（"点下方卡片领取 30 元券"），别让读者思考"那我该干嘛"。

## 4. 滑梯效应（休格曼 · 长文案/销售信/公众号软文专用）

好的长文案是一座滑梯：读者一旦开始，就停不下来，一路滑到 CTA。

- **第一句法则**：广告里所有元素（标题/图/副标）的唯一目的，是让读者读第一句；第一句的唯一目的，是让读者读第二句……逐句勾连到结尾。**第一句要短、要具体、要留疑问**（"减肥并不容易。""向 IBM 致敬。"），不要在第一句做自我介绍、讲公司历史。
- **让读者说"是"**：开头连抛读者一定会认同的判断或处境（"你是不是也…""我们都懂…"），让 TA 一路点头，点头点习惯了，后面就容易顺着你走。
- **好奇心种子**：小节末尾埋钩（"但接下来这点，才是关键""先别急着划走"）。每 300-500 字埋一次，别句句都卖关子。
- **打破思维定势（公理 7）**：写 X 品类文案没灵感时，去相邻品类找答案——写咖啡参考酒类文案，写课程参考健身房的销售话术。

## 5. 影响力六原则话术库（西奥迪尼《影响力》）

写攻心文案时，把六原则当"弹药库"按需取用，别一次打光：

| 原则 | 文案形态 |
|------|---------|
| 互惠 | 先给免费价值（试用/干货包/测评），再要成交——拿了你好处的读者不好意思直接走 |
| 承诺一致 | 先让 TA 做小承诺（收藏/投票/进群/试看），后面推大动作时 TA 倾向保持一致 |
| 社会认同 | "已有 X 万人选择"+ 可晒的真实用户证言（带名字/图更可信） |
| 喜好 | 像朋友说话、站在 TA 一边、敢于自嘲、有真实人设——读者只向"喜欢的人"下单 |
| 权威 | 专家/机构/认证背书，注明来源；权威必须真实 |
| 稀缺 | 限时/限量/名额制，必须是真稀缺 |

**组合原则**：最狠的组合是社会认同+稀缺（"最后 200 份，已有 3 万人抢完"），但稀缺与权威没实据就是虚假宣传，一票否决。

## 6. Slogan / 品牌话语（奥格威 + 特劳特 + 华与华）

品牌一句话记忆点，和卖货文案是两回事：卖货文案负责"这一单"，Slogan 负责"这一辈子被记住"。

**五步公式**：
1. **说人话**：能"说出来"而不是"读出来"（华与华：超级话语要能口头转述）。"怕上火，喝王老吉""今年过节不收礼，收礼还收脑白金"都是能直接说出口的。
2. **占心智**：一句=一个差异化定位。王老吉=怕上火，海飞丝=去屑，沃尔沃=安全。别贪，一个品牌只许占一个词。
3. **给理由/给利益**：说完"我是谁"要给"所以你选我"（不是空喊"XX，更懂你"，要接得住为什么）。
4. **压得短**：≤12 字为佳；能押韵、能重复最好（大脑偏爱节奏与重复）。
5. **口语测试**：念给一个完全不了解的人听，能一次复述=过关；对方要"你再说一遍"=重写。

**Slogan 与文章金句的分工**：金句求"截图传播、单句成立"；Slogan 求"替品牌说话、被反复记住"。写 Slogan 不要套文章金句的排比腔，越像广告腔越记不住。

## 7. 载体适配（结构随载体变，别一套打天下）

| 载体 | 推荐结构 |
|------|---------|
| 电商详情页 | 标题→痛点开场（2-3 个真实场景）→感官沉浸→认知对比→信任证据→价格锚点+算账→CTA+售后兜底 |
| 公众号软文带货 | 真实体验/故事开头（第一句绝不能像广告）→使用场景种草→转折到产品→证据（图/数据/背书）→限时福利→CTA |
| 朋友圈/小红书短文案 | 第一句即钩子→2-3 个场景化卖点（不罗列参数）→真实证言/晒单→CTA+轻稀缺 |
| 信息流/效果广告 | 前 3 秒说清"你是谁+对 TA 有什么用"→短句正文→一个 CTA；信息密度>文采 |
| 私域销售信（长） | 滑梯效应全流程：钩子→认同→放大痛点→方案→证据→价格锚点→风险逆转（退款）→稀缺→CTA |

## 8. 打动人心三板斧（防"参数僵尸"与"自嗨腔"）

1. **具体 > 抽象**：细节是诚实的证据。抽象词（优质/专业/强大）是读者最会跳过的东西。
2. **"你" > "我们"**：全文从读者视角出发。"帮你省下 2 小时"比"我们效率提升 200%"开头更抓人（后者可以当证据用，别当开场白）。
3. **诚实 > 完美**（奥格威：不写你不想让家人看到的广告）：敢于自曝一个小缺点/限制条件反而增信。休格曼经典案例"神奇的烂货"：开篇先狠狠吐槽自己产品长得丑、没显示屏，读者一路笑着读完，反而记住了它的好——真诚是最高级的钩子。

**写砸示范 vs 改法**：
- 参数僵尸："304 不锈钢内胆，12 小时长效保温，一键弹盖" → 场景翻译："冬天开会两小时回来，拧开还是烫嘴的；单手一按就开，抱娃也能喝上热水。"
- 自嗨腔："XX 公司深耕行业 15 年，致力于为客户提供优质服务" → 换成证据与读者利益："同行报价低三成，我们靠什么活 15 年？回头客。"
- 空泛形容词："口感极佳，品质上乘" → 感官占领："第一口是麦香，咽下去有回甘，冰到 4℃最好喝。"

## 9. 合规红线（广告文案专属，叠加七问自检第 1、7 条）

- **绝对化用语**：最/第一/国家级/顶级/极致/全网最低——《广告法》禁止（除非能举证，举证不了别写）。
- **数据必须有出处**：可验证；对比广告须真实客观，不贬损同行。
- **特殊行业**：医疗/保健/金融/教育功效表述从严，不作收益承诺、不暗示疗效、不保本保收益。
- **稀缺促销要真实**：虚假限时/限量/原价 = 虚假宣传。
- **奥格威底线**：不写你不想让家人看到的文案——这条能过滤掉九成灰色玩法。

## 10. 交付前质检清单（卖货文案版）

动笔是四步骨架，交稿前逐项核：

- [ ] Q1-Q4 答得出吗？尤其 Q4"凭什么信"的证据是真实可查的
- [ ] 一句话差异化成立吗（不是人人都能说的废话）？
- [ ] 卖点翻译到"场景体验"层了吗（不是参数罗列）？
- [ ] 四步骨架完整吗？缺的那一步读者会卡在哪？
- [ ] 逐句读：每一句是不是推着 TA 读下一句？滑梯在哪断了？
- [ ] 影响力话术里的稀缺/权威/数据，全部真实可核？
- [ ] 数一下"你"出现了几次——读者视角够不够？
- [ ] 合规扫过：绝对化用语/虚假促销/夸大功效/贬损同行？
- [ ] 念一遍：像不像一个真人在跟朋友安利？不像就回炉去 AI 味（见 de-ai-flavor.md）

**交稿格式**：成品外附一小段「转化逻辑说明」——目标人群、行动目标、四步各用了哪几招、为什么这么排。让用户一眼看懂每句话的用途，而不是只收到一段"感觉还行"的文字。
