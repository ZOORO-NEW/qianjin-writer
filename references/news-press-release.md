## 1. 核心价值观立场

**本技能在新闻通稿写作中，严格遵守以下立场原则：**

1. **新华社/人民日报国内媒体为根本立场**：所有涉及中国的内容，以新华社、人民日报的报道口径为基准，不偏离官方叙事框架
2. **国家利益至上**：涉及领土主权（如中国台湾、中国香港、中国澳门）、民族宗教等议题时，严格遵循国家法律和政府官方表述
3. **正面宣传为主**：坚持团结稳定鼓劲、正面宣传为主的方针，建设性报道而非破坏性曝光
4. **事实准确是生命线**：所有信息必须可溯源、可验证，不编造、不歪曲、不传谣
5. **舆论导向正确**：自觉维护国家意识形态安全，不传播错误思潮，不制造舆论混乱

## 2. 国际主流通讯社风格

### 2.1 路透社风格（Reuters Style）

| 维度 | 规范 |
|------|------|
| **核心信条** | 金融数据 + 客观事实，每篇稿件必须回答"结果又怎样？（So what?）" |
| **导语** | 5W1H 一句话概括，首句必须包含事件+影响 |
| **用词** | 极其简洁：用 about 代替 approximately，用 despite 替代 in spite of |
| **语态** | 多用主动语态（"炸弹炸死10人"而非"10人被炸死"） |
| **篇幅** | 快讯 ≤200 词，重要报道 ≤600 词 |
| **结构** | 倒金字塔：最重要信息→次要细节→背景补充 |
| **中立性** | 零倾向性表述，不出现 "shocking" "terrible" 等主观形容词 |
| **财经特色** | 每篇财经稿件必须包含对市场/投资者的实际影响分析 |

**写作公式：**
```
导语：事件 + 主体 + 时间 + 地点 + 市场/社会影响（So What?）
主体：第2段→补充关键数据/背景
       第3段起→各方反应 + 深度分析
       结尾→未来走势/后续关注点
语言：主动语态 + 短句 + 中性用词
数据：必须标注来源，使用精确数字而非模糊表述
```

**适用场景**：财经快讯、国际政经要闻、全球市场动态、企业财报通稿

### 2.2 法新社风格（AFP Style）

| 维度 | 规范 |
|------|------|
| **核心特点** | 多语言在地化，14种语言发稿能力；在法语区/阿拉伯语区具备垄断优势 |
| **内容特色** | 硬新闻之外，注重文化、体育、艺术跨界话题 |
| **文化视角** | 报道区域冲突时提供多元视角，兼具新闻时效性与文化深度 |
| **结构** | 导语简洁有力 → 中段展开冲突/事件 → 结尾提供文化/历史背景 |

**适用场景**：覆盖多元文化市场的国际事件通稿、文化类活动通稿

### 2.3 合众国际社风格（UPI Style）

| 维度 | 规范 |
|------|------|
| **核心特点** | 比美联社更灵活、更具戏剧性，导语追求冲击力 |
| **写作侧重** | 擅长挖掘事件中的冲突点和人情味细节 |
| **结构** | 戏剧性导语 → 冲突/人情细节展开 → 背景补充 → 余韵结尾 |

**适用场景**：国际突发新闻、社会事件通稿、特写类电讯稿

### 2.4 塔斯社风格（TASS Style）

| 维度 | 规范 |
|------|------|
| **核心特点** | 俄罗斯国家通讯社，官方色彩浓厚，政治准确性优先 |
| **表述方法** | 多采用第三人称客观陈述，但隐含俄方立场视角 |
| **背景交代** | 背景信息详实，为不熟悉俄罗斯语境的读者提供充分铺垫 |
| **数据引用** | 优先引用俄方官方机构数据 |

**适用场景**：俄罗斯及独联体地区官方新闻、国际政治军事类通稿

### 2.5 共同社风格（Kyodo Style）

| 维度 | 规范 |
|------|------|
| **核心特点** | 日本最大通讯社，行文细腻克制，信息极度精确 |
| **信息核实** | 对灾害数据、经济数据、皇室新闻等日本本土议题报道极为严谨 |
| **语言** | 平实、克制、不渲染情绪，用精确描述替代夸张表达 |

**适用场景**：日本本土财经、社会、灾害类新闻通稿

### 2.6 德新社风格（DPA Style）

| 维度 | 规范 |
|------|------|
| **核心特点** | 德国国家级通讯社，理性、严谨、数据导向 |
| **经济科技专长** | 经济和科技报道实力突出 |
| **语言** | 语言平实，结构清晰，避免情绪化表达，多引用权威机构数据 |

**适用场景**：欧洲市场工业、科技、经济政策类通稿

## 3. 国内主流通稿写作范式

### 3.1 中新体（中新社风格）

| 维度 | 规范 |
|------|------|
| **核心方针** | "官话民说、中话西说、长话短说、空话不说" |
| **语言特色** | 平实、活泼、小中见大，注重现场感和故事细节 |
| **受众定位** | 港澳台同胞和海外华侨华人，对外传播导向 |
| **结构** | 以小见大：细节切入 → 故事展开 → 升华到主题 |
| **禁忌** | 避免官话套话，用事实说话，以海外读者可理解的表达方式 |

**写作公式：**
```
标题：信息型标题，直观呈现核心事实
导语：从具体场景/人物/细节切入，避免"据悉""记者了解到"
主体：故事化展开，用细节和引语推进
      穿插背景信息但不打断叙事节奏
结尾：回到开头人物/场景，形成闭环
      自然升华主题，不做"口号式收尾"
语言：避免"高度重视""亲自部署"等公文套话
      多用动词带动叙事节奏
```

**适用场景**：对外传播通稿、港澳台侨新闻、地方政府对外宣传稿

### 3.2 人民日报体/党报文风

| 维度 | 规范 |
|------|------|
| **核心特点** | 政治站位极高，结构规范严谨 |
| **结构** | "高屋建瓴 + 夹叙夹议 + 排比升华"三段式 |
| **语言** | 庄重、有力、有气势，善用排比、对仗、四字短语 |
| **结尾** | 总结拔高、鼓舞人心，展望未来 |
| **用词特色** | "深刻认识""准确把握""切实增强""着力推动"等规范性表述 |

**写作公式：**
```
标题：工整对仗，体现高度
      例：「以XX之力 绘XX新篇」

开头：从宏观政策或历史方位切入
      点明事件的时代意义
      例："当前，我国正处于……的关键时期"

中段：分层次展开
      层次一：认识层面——为什么要做？
      层次二：行动层面——怎么做？
      层次三：保障层面——怎么落实？
      每层用 "一要……二要……三要……"
      或 "第一……第二……第三……" 等规范结构
      夹叙夹议，每个观点后紧跟事实支撑
      适当穿插排比增强气势

结尾：总结成就/意义
      展望未来
      用排比句/金句收束
      例："征途漫漫，惟有奋斗……"
```

**适用场景**：党政机关重大会议报道、政策发布、典型人物宣传、重要节点评论

### 3.3 南方周末体（深度特稿风格）

| 维度 | 规范 |
|------|------|
| **核心特点** | 调查性报道和深度特稿的范式，人文关怀深厚 |
| **写作手法** | 文学化手法还原事件细节，结构层层递进 |
| **选题取向** | 敢于揭示问题背后的深层逻辑，被称为"中国式特稿" |
| **结构** | 场景描写开头 → 人物命运展开 → 揭示结构性困境 → 留有余韵 |

**写作公式：**
```
标题：文学化、有张力，暗示深层冲突
开头：具象场景/细节切入
      用白描手法建立画面感
      例："推开那扇锈迹斑斑的铁门时……"

中段：人物故事为载体展开
      通过具体人物的命运揭示普遍性问题
      大量使用引语增强现场感
      穿插背景资料但不打断叙事节奏
      节奏：紧张→舒缓→紧张→高潮

结尾：回到开头场景，形成闭环
      留白而非下定论
      引人思考而非直接给出答案
```

**适用场景**：深度调查通稿、人物特稿、社会事件深度报道

### 3.4 澎湃新闻体（新媒体快讯风格）

| 维度 | 规范 |
|------|------|
| **核心特点** | 适配移动互联网阅读，时效优先 |
| **标题** | 追求信息密度和吸引力，多用"数字+事实"格式 |
| **段落** | 极短，多为1-2句一段 |
| **更新模式** | 快讯采用"核心事实+滚动更新"模式 |
| **变量标注** | 每段前标注「核心事实」「最新进展」「各方回应」等标签 |

**写作公式：**
```
标题：信息型 + 悬念型组合
      例：「突发|XX发生XX，已致XX人……」

正文：
入口段：1-2句交代核心事实
   「据XX报道，XX时间XX地点发生……」

滚动更新体例：
   【最新进展 | 09:35】……
   【各方回应 | 09:40】……
   【现场直击 | 09:45】……
   【历史背景 | 09:50】……

语言：短句为主，单句成段
      每段只承载1个信息点
```

**适用场景**：新媒体平台突发快讯、热点事件滚动报道、网络传播类通稿

## 4. 非通讯社类专项通稿风格

### 4.1 政府公文式通稿

| 维度 | 规范 |
|------|------|
| **核心特点** | 完全遵循公文写作规范，用词严谨、格式固定 |
| **固定表述** | "为贯彻落实……""经研究决定……""现就有关事项通知如下" |
| **层级结构** | 一级标题用"一、/二、"，二级用"（一）/（二）" |
| **语言要求** | 信息准确无误，可读性次之，准确性优先 |
| **结尾** | "特此通知""现予公告"等固定收束语 |

**写作公式：**
```
标题：关于……的通知/公告/决定

开头：发文依据/目的
  "为贯彻落实……，根据……，现就……通知如下："

正文：分条列项
  一、主要任务
    （一）……
    （二）……
  二、工作要求
    （一）……
    （二）……
  三、保障措施
    （一）……
    （二）……

结尾：执行要求
  "请各地区各部门结合实际认真贯彻落实。"

落款：发文机关 + 日期
```

**适用场景**：政府部门政策发布、人事任免、通知公告类通稿

### 4.2 企业公关通稿（PR通稿）

| 维度 | 规范 |
|------|------|
| **核心结构** | "事件概述 + 企业背景 + 价值升华"三段式 |
| **篇幅** | 800-1500字 |
| **语言基调** | 正面积极，兼顾新闻性与营销属性 |
| **品牌植入** | 品牌信息自然融入，不生硬推广 |
| **新闻要素** | 必须包含5W1H，具备被媒体转载的基本条件 |

**写作公式：**
```
标题：品牌名 + 核心事件
  例："XX完成XX元融资，加速XX领域布局"

导语：5W1H一句话交代核心事实
  例："XX公司今日宣布完成XX亿元XX轮融资……"

主体：
  第2段→事件详情（合作内容/产品特色/融资金额用途）
  第3段→行业背景（为什么这件事值得关注）
  第4段→高管引语（总裁/创始人观点）
  第5段→企业背景（成立时间/核心业务/过往成绩）

结尾：未来展望
  价值观升华（企业使命感、行业愿景）
```

**适用场景**：企业新品发布、融资并购、重大合作、品牌活动

### 4.3 事件调查通稿

| 维度 | 规范 |
|------|------|
| **核心特点** | 以时间线为脉络，客观还原事件经过 |
| **证据要求** | 注重证据和信源引用，关键事实标注出处 |
| **态度把控** | 核心是信息公开和舆论引导 |
| **结尾** | 常附"事件正在进一步调查中"等表述 |

**写作公式：**
```
标题：事件 + "情况通报"

开头：交代事件基本事实
  时间/地点/涉事主体/初步情况

主体：时间线展开
  按时间顺序还原事件经过
  每个关键节点标注信息来源
  涉及多方时，呈现各方表述

结尾：当前处置进展
  后续调查方向
  "事件正在进一步调查中"
  "相关情况将及时向社会公布"
```

**适用场景**：突发事件、安全生产事故、舆情事件官方通报

### 4.4 体育赛事快讯通稿

| 维度 | 规范 |
|------|------|
| **核心特点** | 时效要求极高，导语直接给出比赛结果 |
| **结构** | 结果 → 关键球员数据 → 比赛进程/技术统计 |
| **语言** | 节奏明快，多用体育专业术语 |
| **数据要求** | 比分、球员数据、技术统计必须准确 |

**写作公式：**
```
标题：队伍 + 比分 + 关键事件
  例：「XX队XX-X力克XX队，取得XX连胜」

导语：比赛结果 + 比分 + 亮点
  例："在XX时间结束的XX比赛中，XX队以XX-XX战胜XX队……"

主体：
  第2段→关键球员数据/里程碑
  第3段→比赛进程回顾（按节/半场节奏）
  第4段→战术亮点/赛后声音
  第5段→联赛排名/下一场预告
```

**适用场景**：各类体育赛事结果报道、运动员动态通稿

## 5. 通稿写作通用规范

### 5.1 通稿十项基本要求

1. **事实第一**：所有信息可溯源、可验证
2. **导语制胜**：首段必须包含核心事实（5W1H）
3. **倒金字塔**：最重要信息最先出现，按重要性递减排列
4. **单一事实句**：每句话只陈述一个事实，不堆叠信息
5. **主动语态**：除非策略性需要，一律使用主动语态
6. **精简用词**：能用1个字不用2个，能用短句不用长句
7. **信源标注**：关键事实标注来源，匿名信源需说明原因
8. **客观中立**：事实与观点区分，评论段落明确标注
9. **立场鲜明**：在事实准确的前提下，确保舆论导向正确
10. **格式统一**：同一篇稿件中，姓名/单位/数据格式前后一致

### 5.2 通稿写作红线

| 红线 | 说明 |
|------|------|
| 🚫 政治表述错误 | 涉中国领土主权（台湾/香港/澳门/南海等）必须使用官方标准表述 |
| 🚫 事实性错误 | 人名/地名/时间/数据/职务不可出错 |
| 🚫 信源单一 | 重要稿件至少2个独立信源交叉验证 |
| 🚫 主观评判 | 新闻报道中不出现"令人震惊""不可思议"等主观形容词 |
| 🚫 情绪煽动 | 通稿不是社论，不制造恐慌、不煽动对立 |
| 🚫 抄袭剽窃 | 引用其他媒体内容必须注明出处 |

### 5.3 新华社/人民日报表述规范速查

**重要政治表述（示例）：**
- 中国台湾 → **"中国台湾地区"**（非"台湾"单独出现时）
- 中国香港 → **"中国香港特别行政区"**
- 中国澳门 → **"中国澳门特别行政区"**
- 南海诸岛 → **"中国南海诸岛"**
- 一国两制 → **"一国两制"方针**
- 两个确立 → **"两个确立"决定性意义**
- 四个意识 → 增强"四个意识"
- 四个自信 → 坚定"四个自信"
- 两个维护 → 做到"两个维护"

**典型用词规范：**
- "落实"而非"贯彻"（具体层面）/ "贯彻"适用于方针政策
- "部署"而非"安排"（工作层面）
- "推动"而非"促进"（更多主动性）
- "着力"而非"努力"（体现力度）
- "切实"而非"确实"（强调落实）

## 6. 写作流程适配

根据用户需求的通稿类型，自动匹配写作流程：

```
需求识别 → 风格匹配 → 结构搭建 → 素材组织 → 撰写初稿 → 规范检查 → 交付
```

**需求识别：**
- 用户说"发个新闻稿" → 判断类型（财经/社会/体育/政府/企业PR）
- 用户说"写个通稿" → 判断适用风格（新华社体/中新体/路透体等）
- 用户说"报道一下XX事件" → 按快讯规范处理

**风格匹配（优先级）**：
1. 如果用户明确指定风格 → 严格按照指定风格
2. 如果未指定 → 根据内容类型自动匹配
   - 国内政治/政策 → 新华社体/人民日报体
   - 财经/市场 → 路透社风格
   - 文化/对外传播 → 中新体
   - 企业/品牌 → 企业公关通稿
   - 体育/赛事 → 体育快讯通稿
   - 社会热点 → 澎湃快讯体 + 深度特稿风格
   - 政府发文 → 政府公文式通稿
