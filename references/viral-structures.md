# 爆款文案结构库（v2：反套路结构引擎）

> 旧版按"平台→模板"平铺，所有 AI 写作工具都长这样，于是产出统一的 AI 味。本版改为"节奏/声音 → 结构"的引擎：**强制轮换、强制破升华反射、强制埋 unexpected beat**。结构决定味道，词汇只是表皮。

---

## 一、先诊断：AI 味到底从哪来

不是"值得注意的是""总而言之"这些词（那些能改）。真正露馅的是**信息递送节奏千篇一律**：

1. **升华收尾反射**——几乎每篇最后都要"上升到价值/趋势/呼吁"。真人很少这么收，真人的结尾常是抛个问题、留个钩子、或干脆停在半句。
2. **金句收尾强制**——旧模板写死"结尾金句一句可独立传播"，于是每篇结尾硬憋一句，读者一眼假。
3. **三层递进 uniformity**——现象→剖析→本质，三个小标题排下去，大脑提前预测下一拍，毫无悬念。
4. **清单强制总结**——列完 N 点必补"一句话总结+行动建议"，清单本身有价值，强制升华是累赘。
5. **钩子-案例-小结三段式**——每个论点都是 [观点+案例+金句]，香肠机。
6. **检查表趋同**——末尾"10 项爆款元素"逼每篇打同样的勾，打齐了就都一个味。

**结论**：AI 味 = 可预测。升级方向 = 不可预测 + 有真人的毛边。

## 二、结构七宗罪（写出来就露馅的动作）

| 罪行 | 长什么样 | 改成 |
|------|----------|------|
| 🚫 升华反射 | "在这个 AI 时代，我们更该……" | 停在具体事实或一个未解的问题 |
| 🚫 金句硬收 | 结尾强行"记住，XX 才是 XX" | 金句放文中第三段，结尾松手 |
| 🚫 三段递进 | 一、现象 二、原因 三、本质 | 螺旋深挖，不换小标题 |
| 🚫 清单必总结 | 列完 5 点补"总之……" | 列完就停，或只给一条行动 |
| 🚫 全网同标题 | "别再 XX 了！90% 的人都错" | 见第六节，避开 overuse |
| 🚫 假互动 | "你有什么看法？评论区聊聊" | 抛一个真问题，或根本不互动 |
| 🚫 平均用力 | 每段差不多长、差不多重 | 有长有短，关键段落短到刺眼 |

## 三、新结构库（按"声音/节奏"分，不按平台）

每种标：适用、节奏、禁忌。公众号为主，跨平台复用同理。

### 3.1 螺旋深挖型
一个问题从头挖到尾，不换小标题，越挖越深。
```
[一个刺眼的具体现象]
  ↓ 不问"为什么"，问"为什么是现在"
[把表面原因推翻]
  ↓
[再挖一层，露出利益/结构]
  ↓
[停在最根本的那个矛盾上，不升华]
```
- 适用：行业洞察、反常识分析
- 禁忌：禁止"一/二/三"小标题；禁止结尾升华
- 毛边：最后一段可以只有一句话，甚至半句。

### 3.2 双声辩论型
两个声音互怼，作者不急着站队。
```
[抛出一个流行观点 A]
  ↓
[声音 B 直接反驳，给证据]
  ↓
[声音 A 反咬，承认 B 对一半]
  ↓
[作者收：真正的矛盾在这，没有干净答案]
```
- 适用：有争议话题、价值观碰撞
- 禁忌：禁止"辩证地看"这种和稀泥；两声都要有血有肉
- 毛边：结尾可以留一个两难，不替读者选。

### 3.3 反转推翻型
开头给一个"看起来对"的结论，全文拆了。
```
[先立一个读者大概率认同的判断]
  ↓
[第一刀：这个判断漏了什么]
  ↓
[第二刀：反例]
  ↓
[第三刀：根子在哪]
  ↓
[给出修正后的、更锋利的小判断]
```
- 适用：辟谣、认知纠偏、方法论
- 禁忌：反转不能为反转而反转，推翻后必须站得住
- 毛边：开头那句"假结论"要写得让读者点头。

### 3.4 清单断尾型
列干货，列完就停，不总结。
```
[标题：X 个……]
[开头一句：为什么你需要]
[点1 观点+怎么用]
[点2 观点+怎么用]
[点3 观点+怎么用]
[最后一点之后，没了]
```
- 适用：方法、避坑、资源盘点
- 禁忌：禁止"总之/一句话总结"；禁止每条都配金句
- 毛边：其中一条可以写得特别短，像随手补的。

### 3.5 留白提问型
全文讲完，结尾抛一个问题不答。
```
[场景/判断开头]
[论证，但不给完整结论]
[结尾：一个让人睡不着的问题]
```
- 适用：引发讨论、评论区蓄水
- 禁忌：问题不能假大空；必须是读完全文才懂的那一个
- 毛边：问题越具体越好，别"你怎么看"。

### 3.6 场景沉浸型
几乎不分析，把一个画面写到读者自己得出结论。
```
[一个具体的人，在具体场景里做具体的事]
[细节堆叠，不评论]
[在最有张力的那一刻收]
```
- 适用：人物、故事、情绪赛道
- 禁忌：禁止中途跳出来"这说明"；让读者自己品
- 毛边：可以没有金句，靠画面本身。

### 3.7 口语漫谈型
像跟朋友聊天，看似随意但有主线。
```
[一句大白话开场，带点情绪]
[顺着聊，偶尔跑题再绕回来]
[在聊的过程中把观点递出去]
[结尾随意，像聊天戛然而止]
```
- 适用：人设强、粉丝信任度高的号
- 禁忌：不能真散；三条主线内必须收束
- 毛边：允许"说实话""我也不知道"这种真人语气。

### 3.8 数据证伪型
用一组真实数据，推翻一个流行说法。
```
[流行说法 X]
[数据1 打脸]
[数据2 打脸]
[数据3 打脸]
[真正的结论：X 错在哪]
```
- 适用：行业报告解读、趋势判断
- 禁忌：数据必须真实可核，禁编造（七问第①条一票否决）
- 毛边：可以只给数据不抒情。

## 四、结构轮换与反套路约束（强制）

1. **轮换**：连续两篇不得用同一结构。按 `每日文章` 最近 3 篇的选用结构去重。
2. **默认禁升华**：除非题材硬需要（如年终复盘），否则结尾不用"价值升华/趋势预判/呼吁"三件套。
3. **每篇 ≥ 1 个 unexpected beat**（见第五节）。
4. **金句不上枷锁**：金句允许出现在任意位置，不强制结尾；一篇可以有 0 个被逼出的金句。
5. **长短交错**：正文至少要有 1 段 ≤ 25 字，制造节奏刺点。

## 五、Unexpected Beat 工具箱（埋结构惊喜）

每篇至少挑 1 个用：
- **中途转向**：讲到一半突然"但我得纠正自己一句"。
- **假结尾**：写完一段像收尾了，下一句"等等，还有"。
- **突然短句**：在长篇论证里插一句三个字的段落。
- **金句前置**：最锋利那句放第三段，结尾反而松。
- **自曝其短**："我前年也信这个，后来……"
- **留个矛盾的口子**：结尾不闭合，让读者憋着。

## 六、标题公式（标注烂大街程度）

| 公式 | 示例 | 状态 |
|------|------|------|
| [反常识判断] | 《赢了 7 万的官司，丢了用户的人心》 | ✅ 仍可用 |
| [数字+趋势] | 《2025 年，这 5 个行业将大洗牌》 | ⚠️ 略滥，少用 |
| [人物/企业+冲突] | 《盒马会员店关闭背后的三重失衡》 | ✅ 仍可用 |
| [提问式] | 《产品卖不动，到底是谁的错？》 | ✅ 仍可用 |
| emoji+结果+好奇心 | 🔥终于找到了！XX 天瘦了 XX 斤 | ❌ 小红书烂大街，公众号别用 |
| 别再 XX 了！90% 的人都错 | 别再 XX 了！ | ❌ AI 味最重，禁用 |
| [身份+血泪] | 从业 XX 年，我总结的 X 个铁律 | ⚠️ 可用但别每篇 |

## 七、结构指纹自检（替代旧"10 项爆款元素检查表"）

成稿后过一遍，任一"是"都要改：

- [ ] 结尾是不是又在升华/喊口号？（是→砍）
- [ ] 是不是又三层小标题递进？（是→改螺旋）
- [ ] 金句是不是被逼到结尾？（是→挪到文中）
- [ ] 有没有至少 1 个 unexpected beat？（否→加）
- [ ] 有没有一段短到刺眼？（否→造一个）
- [ ] 这结构和上篇一样吗？（是→换）
- [ ] 通篇读下来，下一拍能不能被预测？（能→打破）

> 旧版"10 项爆款元素检查表"废弃。打齐勾 = 统一的 AI 味。改看"结构指纹"。

## 附录：跨平台速查（保留旧版精华，压缩）

- **小红书**：种草/观点/经验三型仍可用，但标题禁 emoji 堆砌式，正文短句多换行。
- **抖音**：前 3 秒钩子 + 15 秒导入 + 3-5 知识点 + 金句，结构可套 3.8 数据证伪 / 3.3 反转。
- **知乎**：专业分析型可用"先给答案"开头；经验型可套 3.4 清单断尾。
- **B站**：深度分析型保留，但结尾改"留白提问"替代"总结升华"。
