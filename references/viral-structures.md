# 爆款文案结构库

> 收录公众号、小红书、抖音、知乎、B站等平台的爆款内容结构模板

---

## 一、公众号爆款结构

### 1.1 结构A：观点评论型（最常用）

```
【标题】制造认知冲突或价值判断
  ↓
【开头钩子】100字内抛出核心判断或悬念
  ↓
【第一层】现象描述 + 数据支撑
  ↓ 小标题过渡
【第二层】问题剖析 + 案例论证
  ↓ 小标题过渡
【第三层】本质揭示 + 深度分析
  ↓ 小标题过渡
【第四层】价值升华 + 建设性建议
  ↓
【结尾金句】一句话收束，可独立传播
  ↓
【互动引导】自然的评论引导
```

**适用场景**：行业分析、社会评论、商业洞察

**字数**：2500-4000字

### 1.2 结构B：故事叙事型

```
【标题】故事感+悬念
  ↓
【场景切入】一个具体画面，把读者拉进故事
  ↓
【人物登场】有名字、有细节、有对话
  ↓
【矛盾展开】遇到了什么问题/冲突
  ↓
【转折出现】关键事件/认知改变
  ↓
【深度分析】从这个故事看出的行业/社会问题
  ↓
【升华结尾】从个体到群体的价值判断
```

**适用场景**：人物故事、用户洞察、社会观察

**字数**：2000-3500字

### 1.3 结构C：清单干货型

```
【标题】"X个方法/趋势/陷阱/真相"
  ↓
【开头】为什么你需要知道这些
  ↓
【要点1】观点 + 案例 + 小结金句
  ↓
【要点2】观点 + 案例 + 小结金句
  ↓
【要点3】观点 + 案例 + 小结金句
  ↓
...
  ↓
【结尾】一句话总结 + 行动建议
```

**适用场景**：方法总结、趋势盘点、避坑指南

**字数**：2000-3000字

## 二、小红书爆款结构

### 2.1 结构A：种草推荐型

```
【标题】emoji + 核心价值 + 好奇心
例：🔥终于找到了！这个方法让我XX天瘦了XX斤
  
【开头钩子】第一句话就说结果/结论
例：姐妹们！我真的要吹爆这个方法！

【痛点共鸣】你也有这个问题吗？
例：是不是试了N种方法都没用？

【解决方案】分点列出，每点2-3句
1️⃣ 第一步：xxx
2️⃣ 第二步：xxx
3️⃣ 第三步：xxx

【效果展示】具体数据/前后对比

【结尾建议】行动号召 + 互动
例：有同样困扰的姐妹赶紧试试！评论区告诉我效果～

【标签】#话题1 #话题2 #话题3
```

**字数**：500-800字

### 2.2 结构B：观点输出型

```
【标题】反常识/价值判断
例：别再XX了！这才是正确的做法

【开头】直接说结论
例：说一个可能得罪人的观点：XX其实是个伪命题

【论证1】你的理由 + 案例
【论证2】你的理由 + 案例
【论证3】你的理由 + 案例

【金句收尾】一句话总结
例：记住，XX不是目的，XX才是。

【标签】
```

**字数**：500-1000字

### 2.3 结构C：经验分享型

```
【标题】经历 + 结果
例：从XX到XX，我用了XX天，分享我的方法

【开头】背景介绍
例：之前因为XX踩了很多坑，终于找到了正确的方法

【过程分享】时间线/步骤式
📅 第1周：xxx
📅 第2周：xxx
📅 第3周：xxx

【踩坑提醒】避坑指南
❌ 不要这样做：xxx
✅ 应该这样做：xxx

【结尾】鼓励 + 互动
```

**字数**：800-1500字

## 三、抖音短视频文案结构

### 3.1 结构A：知识科普型（1-3分钟）

```
【前3秒钩子】反常识/震撼数据/痛点提问
例："你知道你每天喝的奶茶里有多少糖吗？"

【15秒导入】为什么这个话题和你有关
例："很多人觉得无糖奶茶就没事了，但真相可能吓你一跳。"

【主体内容】3-5个知识点，每个20-30秒
知识点1 + 案例
知识点2 + 案例
知识点3 + 案例

【结尾金句】可截图传播的一句话
例："别被标签骗了，学会看配料表，才是对自己负责。"
```

**字数**：300-600字

### 3.2 结构B：观点评论型（1-2分钟）

```
【前3秒钩子】直接抛观点
例："说个很多人不爱听的事实：XX其实都是XX。"

【15秒论据】给出第一个支撑理由
例："你想想，是不是每次XX的时候，最后XX的都是你？"

【核心论证】展开分析
例："问题的本质不是XX，而是XX。"

【金句收尾】
例："记住，XX从来不是XX的借口。"
```

**字数**：200-400字

### 3.3 结构C：故事叙事型（2-3分钟）

```
【前3秒钩子】故事最戏剧化的瞬间
例："那天，他拿着辞职信走进老板办公室，结果老板说了一句话让他哭了。"

【背景交代】30秒快速交代背景
例："小王在一家公司干了5年，兢兢业业，但是…"

【矛盾展开】1分钟讲冲突
【转折出现】30秒讲变化
【结尾升华】30秒金句收尾
```

**字数**：400-800字

## 四、知乎回答结构

### 4.1 结构A：专业分析型

```
【开头结论】先给答案，不绕弯子
例："先说结论：XX不是XX，而是XX。"

【展开论证】
一、XX的本质是什么
二、为什么会这样
三、正确的做法是什么

【案例支撑】每个论点配1-2个真实案例

【结尾建议】给提问者的具体建议
```

**字数**：1500-3000字

### 4.2 结构B：经验分享型

```
【开头】背景 + 结果
例："从业XX年，做过XX个项目，分享一些血泪教训。"

【干货输出】分点列出，每点有具体操作
1. XX——怎么做，为什么
2. XX——怎么做，为什么
3. XX——怎么做，为什么

【避坑提醒】
"这几个坑我踩过，你们别再踩"

【结尾】一句话总结
```

**字数**：1000-2500字

## 五、B站视频文案结构

### 5.1 结构A：深度分析型（10-15分钟）

```
【开场白】30秒-1分钟
用一个问题或一个反常识的观点开场

【主题引入】1-2分钟
交代背景，为什么这个话题值得聊

【第一层分析】2-3分钟
现象层：发生了什么？
案例 + 数据 + 分析

【第二层分析】2-3分钟
原因层：为什么会这样？
案例 + 数据 + 分析

【第三层分析】2-3分钟
本质层：底层逻辑是什么？
案例 + 数据 + 分析

【总结升华】1-2分钟
金句收尾 + 对未来的判断

【互动引导】30秒
引导弹幕/评论/一键三连
```

**字数**：3000-5000字

## 六、标题生成公式

### 6.1 公众号标题

| 公式 | 示例 |
|------|------|
| [反常识判断] | 《赢了7万的官司，丢了用户的人心》 |
| [数字+趋势] | 《2025年，这5个行业将大洗牌》 |
| [人物/企业+冲突] | 《盒马会员店全面关闭背后的三重失衡》 |
| [提问式] | 《产品卖不动，到底是谁的错？》 |
| [价值判断] | 《营销不是怎么让人买，是怎么让人信》 |

### 6.2 小红书标题

| 公式 | 示例 |
|------|------|
| emoji+结果+好奇心 | 🔥终于找到了！XX天瘦了XX斤的方法 |
| 反常识+痛点 | 别再XX了！90%的人都做错了 |
| 身份+经验 | 从业XX年，我总结的X个铁律 |
| 对比+悬念 | 从XX到XX，我只做对了一件事 |

### 6.3 抖音标题/封面文字

| 公式 | 示例 |
|------|------|
| 震撼数据 | "一杯奶茶=15块方糖" |
| 反常识 | "无糖饮料其实更胖" |
| 痛点提问 | "你的工资对得起你的加班吗？" |
| 悬念 | "老板说完这句话，全场沉默了" |

## 七、爆款元素检查表

每篇稿件完成后，对照以下检查表：

| 元素 | 是否具备 | 说明 |
|------|----------|------|
| 钩子标题 | ☐ | 3秒内抓住注意力 |
| 痛点开头 | ☐ | 前100字内触及读者痛点 |
| 认知颠覆 | ☐ | 至少1处打破常识的判断 |
| 真实案例 | ☐ | 至少2个具体案例 |
| 数据支撑 | ☐ | 至少1组关键数据 |
| 金句传播点 | ☐ | 至少2处可截图传播的金句 |
| 情绪波动 | ☐ | 有起伏，不平淡 |
| 建设性结尾 | ☐ | 有方向，不只指出问题 |
| 行动建议 | ☐ | 读者看完知道该怎么做 |
| 价值观正确 | ☐ | 正能量，不偏激 |
